# Final Output Freeze and Visual Diversity Fix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prevent Hermes Studio from producing final videos where one scene repeats the whole script, the image freezes while TTS continues, or every Google Flow clip uses the same literal visual subject.

**Architecture:** Add an artifact QA layer that inspects finished job folders, then move the detected failures upstream into draft QA, render QA, visual prompt planning, and packaged-runtime verification. The workflow must fail before final render when scene narration repeats the full script or audio duration is too long for a single Flow clip, and it must force visual prompt diversity before Google Flow generation.

**Tech Stack:** Node.js ESM scripts, Electron renderer/main job request, Gemini/OpenRouter draft generation, Google Flow browser automation, Supertonic TTS, ffmpeg/ffprobe-style media probing through existing helpers, existing `npm run check` and mock smoke tests.

## Evidence

### 1. Final duration exceeds selected 60 seconds

`render-options.json` says:

```json
{
  "scriptLengthPreset": "standard",
  "targetSeconds": 60,
  "sceneCount": 5
}
```

But `render-report-v2.json` says:

```json
{
  "finalDuration": 73.83,
  "subtitleEnd": 73.79
}
```

The final output is about `13.83s` longer than the selected target.

### 2. Scene 5 repeats the entire script

`draft.json` scene 5 narration contains all scene 1-4 narration joined together. This is the exact failure pattern:

- Scene 1: intro about wanting meat
- Scene 2: protein/iron explanation
- Scene 3: stress and craving
- Scene 4: body signal and nutrition
- Scene 5: scene 1 + scene 2 + scene 3 + scene 4 repeated as one long narration

This means the workflow rendered the whole script twice in practice: once across scenes 1-4 and again inside scene 5.

### 3. Scene 5 audio is 37 seconds but Flow video is only 8 seconds

`render-report-v2.json`:

```json
{
  "order": 5,
  "videoDuration": 8,
  "audioDuration": 37.07,
  "ratio": 4.63375,
  "strategy": "tpad"
}
```

`scene_audio_manifest.json` confirms:

```json
{
  "order": 5,
  "duration": 36.996795654296875
}
```

This is the direct cause of the freeze: the renderer padded an 8-second video to cover about 37 seconds of audio, so the last frame sits still while TTS continues.

### 4. Visual output is over-literal and repetitive

The contact sheet shows nearly every frame as a young woman eating meat at a restaurant or close-up grill shot. Even if the article topic is related to meat, this is not acceptable storytelling because it repeats the same literal action instead of varying:

- body signal / craving
- protein and iron
- stress response
- nutrition choice
- balanced takeaway

The current prompt in `draft.json` also explains why:

```text
Main subject: the core object or situation from the narration.
Action: a close-up of the key object in use.
Scene keywords: ... 고기 ...
```

Because the planner sees `고기` in every scene and uses generic object/action templates, Google Flow keeps generating meat-eating imagery.

### 5. This job appears to have been generated by an older installed runtime

The job artifacts do not match the current source code contract:

- `job-request.json` does not include `scriptStructure: "hpsl"`.
- `gemini-request.txt` contains the old non-HPSL schema.
- `gemini-response.txt` returned schema placeholder JSON.
- `draft.json` has no `structure: "HPSL"` or `hpsl` object.

Current source code already contains HPSL-related changes, so this specific output likely came from an older packaged app or stale runtime. The plan must therefore include runtime/build fingerprinting and packaged-app verification, not only source fixes.

## Root Cause Summary

Primary causes:

1. Old packaged runtime generated a non-HPSL draft and did not enforce `scriptStructure`.
2. Draft QA did not stop a final scene that repeated the entire script.
3. Render QA in the running app allowed a hard audio/video mismatch and used `tpad`, producing frozen video while TTS continued.
4. Visual prompts were too literal and too generic, causing all Flow clips to converge on the same meat-eating visual.
5. The final artifact was marked `ok: true` even though it had freeze risk, duration drift, and duplicate narration.

```js
#!/usr/bin/env node
import { existsSync, readFileSync } from "node:fs";
import { join, resolve } from "node:path";
import { jaccardSimilarity } from "./youtube-draft-quality.mjs";

function readJson(path, fallback = null) {
  if (!existsSync(path)) return fallback;
  return JSON.parse(readFileSync(path, "utf8"));
}

function compact(text = "") {
  return String(text || "").replace(/[^\p{L}\p{N}]/gu, "").toLowerCase();
}

function repeatsMostOfScript(sceneText = "", script = "") {
  const scene = compact(sceneText);
  const full = compact(script);
  if (!scene || !full || full.length < 20) return false;
  if (scene.includes(full) || full.includes(scene)) return scene.length / Math.max(1, full.length) >= 0.8;
  return jaccardSimilarity(sceneText, script) >= 0.8;
}

export function analyzeYouTubeOutput(jobDirInput) {
  const jobDir = resolve(jobDirInput);
  const draft = readJson(join(jobDir, "draft.json"), {});
  const renderOptions = readJson(join(jobDir, "render-options.json"), {});
  const report = readJson(join(jobDir, "render-report-v2.json"), {});
  const job = readJson(join(jobDir, "job-request.json"), {});
  const failureCodes = [];
  const details = {};

  const targetSeconds = Number(renderOptions.targetSeconds || 0);
  const finalDuration = Number(report.finalDuration || 0);
  if (targetSeconds && finalDuration && Math.abs(finalDuration - targetSeconds) > 3) {
    failureCodes.push("TARGET_DURATION_DRIFT");
    details.targetDurationDrift = { targetSeconds, finalDuration, drift: Number((finalDuration - targetSeconds).toFixed(3)) };
  }

  const scenes = Array.isArray(draft.scenes) ? draft.scenes : [];
  const fullScript = String(draft.script || scenes.map((scene) => scene.narration).join(" "));
  const repeatedScene = scenes.find((scene) => repeatsMostOfScript(scene.narration, fullScript));
  if (repeatedScene) {
    failureCodes.push("DUPLICATE_FULL_SCRIPT_SCENE");
    details.duplicateSceneOrder = Number(repeatedScene.order || 0);
  }

  const hardFreezeScenes = (Array.isArray(report.scenes) ? report.scenes : []).filter((scene) => (
    Number(scene.ratio || 0) > 1.3
    || Number(scene.audioDuration || 0) - Number(scene.videoDuration || 0) > 2
    || String(scene.strategy || "").toLowerCase() === "tpad"
  ));
  if (hardFreezeScenes.length) {
    failureCodes.push("HARD_FREEZE_RISK");
    details.hardFreezeScenes = hardFreezeScenes.map((scene) => ({
      order: scene.order,
      videoDuration: scene.videoDuration,
      audioDuration: scene.audioDuration,
      ratio: scene.ratio,
      strategy: scene.strategy,
    }));
  }

  if (job.sourceType === "url" && (!draft.structure || !draft.hpsl || job.options?.scriptStructure !== "hpsl")) {
    failureCodes.push("MISSING_HPSL_CONTRACT");
    details.hpsl = { draftStructure: draft.structure || "", jobScriptStructure: job.options?.scriptStructure || "" };
  }

  const prompts = scenes.map((scene) => String(scene.image_prompt || "").toLowerCase());
  const meatPromptCount = prompts.filter((prompt) => /meat|steak|grill|고기|restaurant|eating/.test(prompt)).length;
  if (prompts.length >= 3 && meatPromptCount / prompts.length >= 0.8) {
    failureCodes.push("VISUAL_REPETITION_RISK");
    details.visualRepetition = { meatPromptCount, sceneCount: prompts.length };
  }

  return {
    ok: failureCodes.length === 0,
    jobDir,
    failureCodes,
    details,
  };
}

if (process.argv[1] && process.argv[1].endsWith("analyze-youtube-output.mjs")) {
  const result = analyzeYouTubeOutput(process.argv[2] || process.cwd());
  console.log(JSON.stringify(result, null, 2));
  if (!result.ok) process.exitCode = 1;
}
```

```js
function tokenSet(text = "") {
  return new Set(String(text)
    .toLowerCase()
    .replace(/[^\p{L}\p{N}\s-]/gu, " ")
    .split(/\s+/)
    .filter((token) => token.length >= 3)
    .filter((token) => !["the", "and", "with", "scene", "video", "camera", "visual", "goal", "action"].includes(token)));
}

function setSimilarity(left, right) {
  if (!left.size || !right.size) return 0;
  let hit = 0;
  for (const item of left) if (right.has(item)) hit += 1;
  return hit / Math.max(1, left.size + right.size - hit);
}

export function detectVisualRepetition(prompts = [], visualCategories = []) {
  const sets = prompts.map(tokenSet);
  let maxPromptSimilarity = 0;
  let adjacentDuplicateCount = 0;
  for (let index = 1; index < sets.length; index += 1) {
    const similarity = setSimilarity(sets[index - 1], sets[index]);
    maxPromptSimilarity = Math.max(maxPromptSimilarity, similarity);
    if (similarity >= 0.75) adjacentDuplicateCount += 1;
  }

  const categoryCounts = new Map();
  for (const category of visualCategories.filter(Boolean)) {
    categoryCounts.set(category, (categoryCounts.get(category) || 0) + 1);
  }
  const maxCategoryCount = Math.max(0, ...categoryCounts.values());
  const categoryDominance = visualCategories.length ? maxCategoryCount / visualCategories.length : 0;

  return {
    repetitionRisk: prompts.length >= 3 && (
      adjacentDuplicateCount / Math.max(1, prompts.length - 1) >= 0.7
      || categoryDominance >= 0.75
    ),
    maxPromptSimilarity: Number(maxPromptSimilarity.toFixed(3)),
    adjacentDuplicateCount,
    categoryDominance: Number(categoryDominance.toFixed(3)),
  };
}
```
